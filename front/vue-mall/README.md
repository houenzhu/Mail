# 买家端前端（`vue-mall`）

该目录目前仍是 Vue 3 + Vite 的 create-vue 初始脚手架，没有实现买家商城业务页面，也没有接后端 API。商品浏览、登录注册、购物车、下单支付、个人订单等都尚未落地；不要将此目录描述为可用的 C 端商城。

## 启动

```bash
npm install
npm run dev
npm run build
```

当前页面主要是脚手架示例，适合确认开发环境，不代表业务功能验收通过。后端业务接口与状态见 [后端 README](../../backend/SCA-Mail/README.md) 和 [需求文档](../../backend/SCA-Mail/商场微服务项目需求文档（V1.0）.md)。
